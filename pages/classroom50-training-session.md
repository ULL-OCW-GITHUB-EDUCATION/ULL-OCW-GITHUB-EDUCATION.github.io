# Classroom 50 Training Session

Este video en YouTube "[Classroom 50 Training Session](https://youtu.be/gpIz6XEVlEE?si=spbnHJnVeQZFglR3)" (24 julio de 2026) contiene una introducción a Classroom 50 por sus creadores. Está orientado a profesores con conocimientos de GitHub y GitHub Classroom y explica 
- La [interfaz web para profesores](https://github.com/foundation50/classroom50/wiki/Web-Teacher-Guide) 
- La [interfaz web para estudiantes](https://github.com/foundation50/classroom50/wiki/Web-Student-Guide)
- La extensión de GitHub CLI para el profesor 
  - [gh-teacher guide](https://github.com/foundation50/classroom50/wiki/CLI-Teacher-Guide) y 
  - [gh teacher reference](https://github.com/foundation50/classroom50/wiki/gh-teacher) 
- La extensión de GitHub CLI para el estudiante
  - [gh-student guide](https://github.com/foundation50/classroom50/wiki/CLI-Student-Guide)
  - [gh student reference](https://github.com/foundation50/classroom50/wiki/gh-student).

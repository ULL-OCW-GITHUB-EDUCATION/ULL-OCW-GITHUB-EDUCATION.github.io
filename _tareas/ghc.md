# Classroom 50 para Profesores

## Objetivos

En este capítulo aprenderemos:

* Que es [Classroom 50](https://github.com/foundation50/classroom50/wiki) desde la perspectiva del profesor 
* Aprenderemos a crear una asignación Individual 
* Aprenderemos a crear una asignación de grupo 

## Introducción a GitHub Classroom

Para poder llevar a cabo la tarea de crear un classroom y hacer las asignaciones deberás leer con detenimiento 

- [Web Teacher Guide](https://github.com/foundation50/classroom50/wiki/Web-Teacher-Guide)
- [CLI Teacher Guide](https://github.com/foundation50/classroom50/wiki/CLI-Teacher-Guide)
- [Staff, TAs, and Multiple Teachers](https://github.com/foundation50/classroom50/wiki/Staff-TAs-and-Multiple-Teachers)
- [Course Lifecycle and End of Term](https://github.com/foundation50/classroom50/wiki/Course-Lifecycle-and-End-of-Term)


## Objetivos y Entrega de tareas para este Capítulo

* Crea una asignación Individual Classroom 50 para el Classroom 50 que creaste en la primera práctica. Crea un repo template para la práctica. Documenta lo que has hecho en el fichero `README.md`  de tu repo de entrega
* Crea una asignación de grupo Classroom 50 para el Classroom 50 que creaste en la primera clase. Crea un repo template para la práctica.Documenta lo que has hecho en el fichero `README.md`  de tu repo de entrega
